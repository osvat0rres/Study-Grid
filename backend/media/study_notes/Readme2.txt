Problem # 2: String Run Encoding
This program will replace all identical characters in a lowercase string and 
compress the string into a copy of the character followed by a count of 
how many times the character appears to ensure it takes less space. 
This problem is known as the String Run Encoding. 


Requirements: 
Python 3.12
VS Code 
Runs on Windows or Linux

How To Run
1. Save the program file (compressstrings.py)
2. Open a terminal 
3. Run the program (click on the play button in top of VS code to run terminal)
4. User is prompted to enter a string (lowercase only)
5. The program will output a compressed string 
6. To exit the program the user can input exit

Example Input/Output : 

Enter a string: helloooooooo there
Compressed string: hel8o there

To exit the program: 
Enter a string: exit
